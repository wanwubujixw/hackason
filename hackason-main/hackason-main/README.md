## 一、项目简介

### 一句话介绍
**校园里的一封温柔回信 —— 情绪匹配真实校园场景，给你一个可执行的小行动。**

### 项目背景
大学生在校园里经常有短暂的情绪起伏：上课累了、考试压力大、一个人吃饭有点孤独…… 这些时刻不一定需要专业帮助，但一个温柔的提醒、一个可执行的小行动，能帮我们更快地回到好状态。

### 目标用户
高校在读本科生、研究生，愿意花 1~2 分钟获得一点小温暖的校园年轻人。

### 产品理念
不解决心理疾病，只在情绪的"轻"时刻提供温柔陪伴。从**情绪选择 → 场景匹配 → 回信卡生成 → 收藏反馈**，形成完整的情绪闭环。

---

## 二、项目特色与创新点

### 1. 情绪 × 真实校园场景的多维匹配
不是泛泛的"推荐鸡汤"，而是结合 **心情 + 可用时间 + 场景偏好 + 社交舒适度** 四个维度，从真实校园场景库中筛选出最合适的推荐。比如同样是疲惫，只有 5 分钟和有 30 分钟，推荐的地点完全不同。

### 2. 「校园回信卡」作为产品载体
每次推荐不是一个"列表项"，而是一张**温柔的回信卡**——有安慰文案、推荐地点、选择原因、小行动、温柔结束语，像真的收到了一封来自校园角落的信。

### 3. 零依赖、零付费 API 的轻量实现
**纯静态 Web 应用**，不需要 Node.js、不需要后端服务器、不需要大模型 API、不需要账号登录。双击 `index.html` 就能跑，任何人在任何电脑上都能使用。所有推荐逻辑和回信文案都是本地实现，不收集任何用户数据。

### 4. 完整的 MVP 情绪闭环
从打开首页 → 选择心情 → 设置时间和偏好 → 获得地点推荐 → 生成回信卡 → 收藏或反馈，**每一步都可运行**。优先保证闭环跑通，不堆积用不起来的功能。

## 四、项目技术栈

| 类别 | 技术 | 说明 |
|---|---|---|
| 前端框架 | 无（原生 HTML/CSS/JavaScript） | 零框架、零构建、零依赖 |
| 模块系统 | ES 模块（`<script type="module">`） | 现代浏览器原生支持，便于分模块协作 |
| 数据存储 | localStorage（浏览器本地存储） | 收藏和反馈持久化，不收集用户数据 |
| 样式 | 原生 CSS + CSS 变量 | 主题变量在 :root 里，一处改全站生效 |
| Git | Git + GitHub | 版本管理和协作 |
| 运行环境 | 任何现代浏览器 | Chrome / Edge / Firefox / Safari 最新版 |

### 为什么选择纯静态？
1. **零安装**：五个人不用装 Node.js、npm 或构建工具，双击就能跑
2. **低学习成本**：HTML/CSS/JS 是任何编程教程都覆盖的基础
3. **天然隔离**：五人各管各的 JS 文件，几乎不会 Git 冲突
4. **两天内可交付**：不需要花时间配环境、跑构建、调 bug

## 七、完整安装教程（从零开始）

### 步骤 1：安装 Git（如果还没装）
去 https://git-scm.com/download/win 下载 Windows 版，安装时一路 Next 即可。

安装完打开 PowerShell，验证：
```powershell
git --version
```

### 步骤 2：安装 VS Code（推荐）
去 https://code.visualstudio.com/ 下载安装。安装时勾选"Add to PATH"选项。

### 步骤 3：克隆仓库
打开 PowerShell，运行：
```powershell
# 把 URL 换成你在 GitHub 上创建的仓库地址（A 负责人提供）
git clone https://github.com/你的GitHub用户名/hackason.git

# 进入项目目录
cd hackason
```

### 步骤 4：启动项目
**不需要 npm install、不需要 npm run dev**。直接：
1. 在文件资源管理器里找到 `hackason/index.html`
2. 双击它

浏览器应该会打开应用。你会看到一个简单的标题和骨架界面。

或者用 VS Code：
1. 打开 VS Code
2. 菜单 File → Open Folder → 选择 hackason 目录
3. 右键 index.html → "Open with Live Server"（需要装 Live Server 插件）

### 步骤 5：确认项目正常运行
- 页面能打开，没有空白
- 控制台（F12）没有红色报错
- 标题显示"解忧慢递邮局"

### 常见错误解决

| 错误 | 原因 | 解决 |
|---|---|---|
| 页面打开后控制台报 CORS 错误 | 直接用 file:// 协议打开时，ES 模块可能被浏览器拦截 | 用 VS Code Live Server 或 Python `python -m http.server` 启本地服务器 |
| 克隆时提示 Permission denied | 没加为仓库 Collaborator | 让 A 负责人在 GitHub 仓库 Settings → Collaborators 里加上你的 GitHub 账号 |
| Git push 被拒绝 | 你在推 main 分支 | 切回自己的分支再推：`git checkout feat/home-ui` |

### 示例一：疲惫，只有 5 分钟，想独处

**用户输入**：
- 心情：疲惫 😴
- 可用时长：5 分钟
- 场景偏好：安静
- 社交舒适度：希望独处

**系统筛选逻辑**：
1. 按 `tags` 匹配 → 匹配到 `scene-001`（图书馆，tags 含 tired）
2. 按 `timeRange` 过滤 → 5 分钟只匹配 timeRange 含 5 的场景
3. 按 `socialTags` 匹配 → 匹配 socialTags 含 alone 的

**推荐结果**：
- 兜底：`scene-003`（食堂一楼热饮窗口，socialTags 含 small/crowded，匹配度较低但兜底）

**可能的回信卡**：
```
💌 今天辛苦了，找个安静的地方歇一歇吧。食堂一楼的热饮窗口旁边很温馨，
    一杯热奶茶的时间，让自己慢慢停下来。

📍 推荐地点：食堂一楼的热饮窗口
📝 选择原因：孤独或迷茫时，一口热饮能让你感受到校园里的烟火气。
👉 小行动：买一杯热奶茶或热豆浆，慢慢喝完。
💛 慢慢来，一切都还来得及。
```

**收藏 / 反馈**：
- 点 ✉️ 收藏 → 数据写入 localStorage，可在收藏列表查看
- 点 👍 适合我 / 👎 不太适合我 → 反馈数据写入 localStorage

## 九、功能使用教程

### 步骤 1：打开首页
双击 `index.html`（或用 VS Code Live Server）。看到"✉️ 解忧慢递邮局"标题。

### 步骤 2：选择心情
> （骨架阶段：心情按钮由 B 模块渲染）
点击 6 种心情之一：😴 疲惫 / 😤 烦躁 / 💧 低落 / 🌙 孤独 / 🌫️ 迷茫 / 🌸 平静

### 步骤 3：选择可用时长
点击 3 个时长选项之一：⏱️ 5 分钟 / ⏱️ 15 分钟 / ⏱️ 30 分钟

### 步骤 4：选择场景偏好
> （可选，骨架阶段由 B 模块实现）
勾选你现在希望的场景特征：安静 / 自然 / 适合散步 / 有生活气息

### 步骤 5：选择社交舒适度
点击你的社交偏好：希望独处 / 可以接触少量人群 / 希望热闹氛围

### 步骤 6：查看推荐结果
系统会显示 2~3 个匹配到的校园场景，按匹配度排序。

### 步骤 7：生成回信卡
点击某一个推荐场景，会生成一张完整的回信卡。

### 步骤 8：收藏或反馈
- 点 ✉️ **收藏** → 这张回信卡会保存到本地
- 点 👍 **适合我** 或 👎 **不太适合我** → 你的反馈会保存到本地

### 步骤 9：查看收藏
从首页进入收藏列表，查看之前保存的回信卡。

## 十二、Git 开发记录

本项目通过 GitHub 进行版本管理。完整 Git 协作教程见 [docs/GIT_WORKFLOW.md](./docs/GIT_WORKFLOW.md)。

### 分支结构
- `main`：主分支，A（项目负责人）维护，所有人的代码最终合并到这里
- `feat/home-ui`：B（首页 UI）的开发分支
- `feat/campus-data`：C（校园场景数据）的开发分支
- `feat/matcher-letter`：D（匹配 + 回信）的开发分支
- `feat/favorites-feedback`：E（收藏 / 反馈 / 测试）的开发分支

### 查看提交记录
```bash
# 查看所有提交（一行一条）
git log --oneline --decorate --all

# 查看黑客松比赛时间范围内（2026-10-23 ~ 2026-10-25）的提交
git log --since="2026-10-23 00:00:00" --until="2026-10-25 20:00:00" --all --date=local
```

### Git 记录原则
- ✅ 每次完成一个小目标就 commit（一天至少 3~5 条）

3. **界面功能**：当前只有骨架，完整 UI 由 B 模块在两天内填充。
