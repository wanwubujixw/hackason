# 项目定位与 MVP 范围

## 一句话介绍
当校园里的你感到疲惫、烦躁、孤独或迷茫时，选择一下当下的心情和可用时间，
我们会给你一张专属的「校园回信卡」，并推荐一个适合此刻的校园地点。

## 要解决的问题
大学生在校园里经常会有短暂的情绪起伏：上课累了、考试压力大、一个人吃饭有点孤独……
这些时刻不一定需要专业帮助，但一个温柔的提醒、一个可执行的小行动，
能帮我们更快地回到好状态。

## 目标用户
- 高校在读本科生、研究生
- 在校园里生活和学习的年轻人
- 愿意花 1~2 分钟选择心情、获得一点小温暖的人

## 核心价值主张
- **情绪 → 场景** 的匹配：根据你的心情，推荐校园里真实存在的地点
- **轻量、温柔**：不承诺解决心理问题，只提供一个温柔的提醒和一个小行动
- **本地实现**：所有推荐逻辑和回信文案都在本地，不用付费 API，不收集用户数据

---

## MVP 功能范围（两天内必须完成的）

| 模块 | MVP 要求 | 负责人 |
|---|---|---|
| 首页 + 心情选择 | 用户能选择 6 种心情之一 | B |
| 时间 + 偏好选择 | 3 档时间 + 社交舒适度 | B |
| 场景匹配 | 能从场景库中筛选出推荐 | D |
| 回信生成 | 能生成一张回信卡 | D |
| 收藏 + 反馈 | 用户能收藏回信、给出反馈 | E |
| 完整闭环 | 首页 → 选择 → 推荐 → 回信 → 收藏/反馈 跑通 | 全体 |
