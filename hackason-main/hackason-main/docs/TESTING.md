## 四、localStorage 限制说明（如实告知用户）

- 收藏和反馈数据存储在 **浏览器本地**
- 同一浏览器同一电脑上才能读取
- **清除浏览器数据会丢失所有记录**
- 换电脑 / 换浏览器 / 换手机都看不到之前的数据
- **不会上传到任何服务器，不会被他人访问**
