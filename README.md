## 一、项目简介

### 一句话介绍
**校园里的一封温柔回信 —— 情绪匹配真实校园场景，给你一个可执行的小行动。**

### 项目背景
大学生在校园里经常有短暂的情绪起伏：上课累了、考试压力大、一个人吃饭有点孤独…… 这些时刻不一定需要专业帮助，但一个温柔的提醒、一个可执行的小行动，能帮我们更快地回到好状态。

### 目标用户
高校在读本科生、研究生，愿意花 1~2 分钟获得一点小温暖的校园年轻人。

### 产品理念
不解决心理疾病，只在情绪的"轻"时刻提供温柔陪伴。从**情绪选择 → 场景匹配 → 回信卡生成 → 收藏反馈**，形成完整的情绪闭环。

---

## 二、项目特色与创新点

### 1. 情绪 × 真实校园场景的多维匹配
不是泛泛的"推荐鸡汤"，而是结合 **心情 + 可用时间 + 场景偏好 + 社交舒适度** 四个维度，从真实校园场景库中筛选出最合适的推荐。比如同样是疲惫，只有 5 分钟和有 30 分钟，推荐的地点完全不同。

### 2. 「校园回信卡」作为产品载体
每次推荐不是一个"列表项"，而是一张**温柔的回信卡**——有安慰文案、推荐地点、选择原因、小行动、温柔结束语，像真的收到了一封来自校园角落的信。

### 3. 零依赖、零付费 API 的轻量实现
**纯静态 Web 应用**，不需要 Node.js、不需要后端服务器、不需要大模型 API、不需要账号登录。双击 `启动本地预览.bat` 即可运行（脚本用 Windows 自带的 PowerShell 起一个本地静态服务器），任何人在任何 Windows 电脑上都能使用。所有推荐逻辑和回信文案都是本地实现，不收集任何用户数据。

### 4. 完整的 MVP 情绪闭环
从打开首页 → 选择心情 → 设置时间和偏好 → 获得地点推荐 → 生成回信卡 → 收藏或反馈，**每一步都可运行**。优先保证闭环跑通，不堆积用不起来的功能。

## 四、项目技术栈

| 类别 | 技术 | 说明 |
|---|---|---|
| 前端框架 | 无（原生 HTML/CSS/JavaScript） | 零框架、零构建、零依赖 |
| 模块系统 | ES 模块（`<script type="module">`） | 现代浏览器原生支持，便于分模块协作 |
| 数据存储 | localStorage（浏览器本地存储） | 收藏和反馈持久化，不收集用户数据 |
| 样式 | 原生 CSS + CSS 变量 | 主题变量在 :root 里，一处改全站生效 |
| Git | Git + GitHub | 版本管理和协作 |
| 运行环境 | 任何现代浏览器 | Chrome / Edge / Firefox / Safari 最新版 |

### 为什么选择纯静态？
1. **零安装**：五个人不用装 Node.js、npm 或构建工具，双击「启动本地预览.bat」即可运行
2. **低学习成本**：HTML/CSS/JS 是任何编程教程都覆盖的基础
3. **天然隔离**：五人各管各的 JS 文件，几乎不会 Git 冲突
4. **两天内可交付**：不需要花时间配环境、跑构建、调 bug

## 七、完整安装教程（从零开始）

### 步骤 1：安装 Git（如果还没装）
去 https://git-scm.com/download/win 下载 Windows 版，安装时一路 Next 即可。

安装完打开 PowerShell，验证：
```powershell
git --version
```

### 步骤 2：安装 VS Code（推荐）
去 https://code.visualstudio.com/ 下载安装。安装时勾选"Add to PATH"选项。

### 步骤 3：获取代码
仓库是公开的，克隆不需要任何权限。打开 PowerShell，运行：
```powershell
git clone https://github.com/wanwubujixw/hackason.git

# 进入项目目录
cd hackason
```

如果不想装 Git，也可以在 GitHub 仓库页面点 **Code → Download ZIP**，解压后进入 `hackason` 目录。

### 步骤 4：启动项目
**不需要 npm install、不需要 npm run dev**。直接：
1. 在文件资源管理器里找到 `hackason/启动本地预览.bat`
2. 双击它

脚本会用 Windows 自带的 PowerShell 启动本地静态服务器（默认 8000 端口，被占用时自动顺延到 8010），并自动打开浏览器。看到"✉️ 解忧慢递邮局"首页即启动成功。

> 为什么不能直接双击 `index.html`：项目使用浏览器原生 ES Modules，`file://` 协议下会被浏览器拦截，页面会空白。

**macOS / Linux 用户**：在项目根目录执行 `python3 -m http.server 8000`，然后浏览器访问 http://localhost:8000/ 即可（不需要安装任何依赖）。

或者用 VS Code：
1. 打开 VS Code
2. 菜单 File → Open Folder → 选择 hackason 目录
3. 右键 index.html → "Open with Live Server"（需要装 Live Server 插件）

### 步骤 5：确认项目正常运行
- 页面能打开，没有空白
- 控制台（F12）没有红色报错
- 标题显示"解忧慢递邮局"

### 常见错误解决

| 错误 | 原因 | 解决 |
|---|---|---|
| 页面打开后控制台报 CORS 错误 | 直接用 file:// 协议打开时，ES 模块可能被浏览器拦截 | 用 VS Code Live Server、`启动本地预览.bat` 或 `python -m http.server` 启本地服务器 |
| 双击 `启动本地预览.bat` 没反应 | PowerShell 执行策略或端口被占用 | 右键「以管理员身份运行」，或改用 `python -m http.server 8000` |
| `git push` 被拒绝 | 没有仓库写权限，或直接推送受保护的 `main` | 用自己的分支修改后发起 Pull Request；只在有权限时推送 |

## 八、完整运行示例

> 以下为 2026-10-25 场景数据调整后在 15 条真实场景数据上重新核对的结果。场景数据再调整后，推荐结果可能变化。

### 示例 1：疲惫，有 15 分钟，想安静独处

**用户输入**：
- 心情：疲惫 😴
- 可用时长：15 分钟
- 场景偏好：安静
- 社交舒适度：希望独处

**系统筛选逻辑**：
1. `tags` 含 `tired` → 命中 +3
2. `timeRange` 含 `15` → 命中 +2
3. `socialTags` 含 `alone` → 命中 +2
4. `type` 为咖啡馆（对应偏好"安静"）→ 命中 +1
5. 按总分从高到低排序，取前 3 条；0 分场景不展示

**实际推荐结果**：
1. 咖啡馆 · 南湖综合楼水吧（scene-008，四类条件全部命中）
2. 生活 · 文学院（scene-002）
3. 自然 · 梅园（scene-013）

**回信卡（选择第一个场景）**：
```
💌 今天辛苦了，找个安静的地方歇一歇吧。校园里总有一个角落在等你——
    不如就去「南湖综合楼水吧」坐一会儿，什么都不用做，发呆也好，闭眼也好。

📍 推荐地点：南湖综合楼水吧
📝 选择原因：静不下心学习的时候，来这个没有干扰、只有书和桌椅的角落坐下，很容易就进入状态。
👉 小行动：给自己定一个小目标，学完就起身休息。
💛 你值得所有的好。✨（结束语从 4 句中随机选一句）
```

**收藏 / 反馈**：
- 收藏写入 localStorage 的 `jyo_favorites`（含 sceneId / place / mood / 正文 / 时间），再次点击可取消收藏
- 反馈写入 `jyo_feedbacks`（good / bad），提交后按钮置灰不可重复提交

**无匹配时**：`matchScenes` 返回空数组会启用兜底场景 `scene-012`（南湖前面的空地）与 `scene-002`（文学院），并显示"没有找到完全合适的地点"提示。

### 示例 2：低落，有 15 分钟，想待在自然里

**用户输入**：
- 心情：低落 💧
- 可用时长：15 分钟
- 场景偏好：自然
- 社交舒适度：希望独处

**打分过程**（同一套规则）：
- 南湖前面的空地：心情 +3、时长 +2、独处 +2、自然 +1 = **8**
- 外国语学院门口的林荫空地：心情 +3、时长 +2、独处 +2、自然 +1 = **8**
- 文学院：心情 +3、时长 +2、独处 +2、类型不是自然场景 = **7**

**实际推荐结果**：
1. 自然 · 南湖前面的空地（scene-012）
2. 自然 · 外国语学院门口的林荫空地（scene-015）
3. 生活 · 文学院（scene-002）

**回信卡（选择第二个场景）**：
```
💌 心情不好的时候，风会带走一部分烦恼。找个温暖的角落，让自己静一静，不用急着振作，也不用假装没事。去「外国语学院门口的林荫空地」待一会儿吧，低落会过去，而你会比想象中更有力量。

📍 推荐地点：外国语学院门口的林荫空地
📝 选择原因：情绪低落、心里堵得慌的时候，来这片偏僻安静的林荫空地走一走。没人经过，不用忍着，想哭想骂都可以，发泄完会轻松一点。
👉 小行动：沿着林荫道走到最里面，找个没人的角落坐十分钟。
💛 慢慢来，一切都还来得及。💌（结束语从 4 句中随机选一句）
```

> 两个示例说明：推荐结果不是写死的，而是由「心情 / 时长 / 社交 / 偏好」四项打分实时计算；同样的"疲惫"，换成 5 分钟或换一种社交偏好，前三名就会变化。

## 九、功能使用教程

### 步骤 1：打开首页
双击 `启动本地预览.bat`（或运行 `python -m http.server 8000` 后访问 http://localhost:8000）。看到"✉️ 解忧慢递邮局"标题。

### 步骤 2：选择心情
点击 6 种心情之一：😴 疲惫 / 😤 烦躁 / 💧 低落 / 🌙 孤独 / 🌫️ 迷茫 / 🌸 平静

### 步骤 3：选择可用时长
点击 3 个时长选项之一：⏱️ 5 分钟 / ⏱️ 15 分钟 / ⏱️ 30 分钟

### 步骤 4：选择场景偏好
勾选你现在希望的场景特征（可多选）：安静 / 自然 / 适合散步 / 有生活气息 / 有食物

### 步骤 5：选择社交舒适度
点击你的社交偏好：希望独处 / 可以接触少量人群 / 希望热闹一点

### 步骤 6：查看推荐结果
系统会显示 1~3 个匹配到的校园场景，按匹配度排序；没有匹配时展示兜底场景。

### 步骤 7：生成回信卡
点击某一个推荐场景，会生成一张完整的回信卡。

### 步骤 8：收藏或反馈
- 点 ✉️ **收藏** → 这张回信卡会保存到本地；再点一次即可取消收藏
- 点 👍 **适合我** 或 👎 **不太适合我** → 你的反馈会保存到本地

### 步骤 9：查看收藏
从回信页进入收藏列表，查看之前保存的回信卡，也可以在这里取消收藏。

## 十四、已知限制与未来计划

### 当前已知限制（诚实告知）
1. **场景数据**：当前 src/data/scenes.js 共 15 条华中师范大学真实地点，`dataSource` 均标注为"已核实"；但暂未配图（`imagePath` 为空），界面以文字为主。
2. **回信文案**：使用 6 套心情模板 + 4 句随机结束语，未接入大模型；同一心情多次生成正文相同，只有结束语会变化。
3. **界面功能**：完整流程已可运行；手机端已实现 640px CSS 响应式断点，并在 375×812 宽度下验证无横向溢出，但未做真机触控逐项验证；桌面端依赖手动回归。
4. **数据持久化**：收藏和反馈用浏览器 localStorage，**清除浏览器数据或换电脑就会丢失**。不跨设备同步，不上传到任何服务器。
5. **没有错误上报**：如果用户遇到 bug，没有自动错误上报机制，靠手动反馈。
