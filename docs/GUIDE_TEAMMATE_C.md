# 队友 C：校园场景数据（操作指南）

---

## 你需要准备的

1. **VS Code**（装过了就跳过）→ https://code.visualstudio.com/
2. 一个 **AI 助手**（任选一个）：TRAE / Cursor / VS Code Copilot

---

## 步骤 1：下载项目 zip 包

负责人发你 `hackason.zip`，解压到 **D:\hackason**。

---

## 步骤 2：用 VS Code 打开项目

打开 VS Code → File → Open Folder → 选择 D:\hackason。

---

## 步骤 3：先想一下你要写什么（5 分钟，在微信里打字就行）

你是**最了解校园的人**！在 AI 帮你写之前，先在心里或者微信里列一下：

> 校园里哪些地方能让人放松、适合不同心情？
> - 疲惫时我常去 ________
> - 烦躁时我常去 ________
> - 低落时我常去 ________
> - 孤独时我常去 ________
> - 迷茫时我常去 ________
> - 平静时我常去 ________

**至少列 8~10 个地点**。给每个地点想：
- 一个好听的名字（比如"图书馆三楼窗边阅读区"而不是"图书馆"）
- 50 字描述（比如"安静的角落，靠窗有自然光，周围只有翻书声"）
- 推荐理由（为什么适合这种心情）
- 什么心情适合（对应 tired / irritated / down / lonely / confused / peaceful）
- 适合呆多久（5 / 15 / 30 分钟）
- 社交舒适度（alone / small / crowded）
- 一个小行动建议（比如"找一本你想读的书翻 5 页"）

把你写的这些**发给负责人**（或直接跟 AI 说），这样数据就是你原创的了！

---

## 步骤 4：让 AI 帮你写成代码

打开你的 AI 助手，**复制粘贴下面这段**（把你想的真实校园地点告诉它）：

```
我是大一学生，完全不会写代码，在参加黑客松比赛。
请你帮我把校园场景整理成 JavaScript 数据文件。

项目位置：D:\hackason

我已经想好了这些真实的校园地点（这些是我原创的）：
（在这里把你步骤 3 里写的 8~10 个真实地点列出来，比如：
- 图书馆三楼窗边阅读区：安静、适合疲惫和平静、独处、15-30分钟
- 校园湖边的长椅：有绿树、适合低落孤独、少量人群、5-30分钟
- 食堂一楼热饮窗口：有烟火气、适合孤独迷茫、热闹、5-15分钟
- ...）

请帮我写 src/data/scenes.js 文件，把这些真实地点填进去。

格式参考文件里已有的 3 条演示数据，每条场景必须包含：
- id: 唯一编号 scene-001 / scene-002 / ...
- name: 真实地点名称
- type: 类型（图书馆/自然/食堂/操场/咖啡馆/走廊 等）
- description: 50~100 字描述
- reason: 推荐理由
- tags: 心情标签数组（从这 6 个里选：tired / irritated / down / lonely / confused / peaceful）
- timeRange: 时长数组（从 [5] / [15] / [30] / [5,15] / [15,30] / [5,15,30] 里选）
- socialTags: 社交数组（从 alone / small / crowded 里选）
- smallAction: 一个可执行的小行动
- imagePath: 暂时留空字符串 ""
- dataSource: 写"已核实"（因为是你真实去过的），如果你编的就写"演示数据"

不要改文件里的其他内容（顶部注释、import 语句、export { SCENES }），
只把中间的 SCENES = [ ... ] 里替换成你写的真实数据。

写完告诉我"可以保存了"。
```

---

## ⚠️ 重要规则

- **只改 src/data/scenes.js**（和 src/data/moods.js 如果你要加心情）
- **不要碰** src/services/、src/pages/、src/styles/ 里的任何文件
- **dataSource 字段**必须诚实写！真实去过的写"已核实"，编的写"演示数据"
- **tags 的值**只能是那 6 个英文单词，不能自己造
- **timeRange 的值**只能是 5 / 15 / 30 这三个数字
