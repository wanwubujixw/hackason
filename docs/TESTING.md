## 一、测试环境

- 操作系统：Windows 11
- 浏览器：Chrome（最新版）
- 测试方式：本地静态服务器 `python -m http.server 8123`，浏览器访问 http://localhost:8123/
  - 项目使用原生 ES Modules，**不能直接双击 index.html**（`file://` 会被浏览器拦截导致白屏），必须通过 HTTP 打开
- 场景数据：`src/data/scenes.js` 12 条真实校园场景

## 四、localStorage 限制说明（如实告知用户）

- 收藏和反馈数据存储在 **浏览器本地**
- 同一浏览器同一电脑上才能读取
- **清除浏览器数据会丢失所有记录**
- 换电脑 / 换浏览器 / 换手机都看不到之前的数据
- **不会上传到任何服务器，不会被他人访问**
