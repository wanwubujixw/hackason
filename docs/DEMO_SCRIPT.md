# 黑客松现场演示脚本（3~5 分钟）

> 本文件由 A 模块整理，内容已与当前 main 分支的真实界面、真实场景数据逐项核对。
> 演示前把流程走一遍，不要现场翻文档。

---

## 演示前准备（务必完成）

1. **打开方式**：本项目使用原生 ES Modules，**不能双击 index.html**（`file://` 会被浏览器拦截，页面白屏）。
   - 推荐：双击项目根目录的「启动本地预览.bat」，会自动起服务并打开浏览器；或运行 `python -m http.server 8123` 后访问 `http://localhost:8123/`
   - 备用：如果 GitHub Pages 已开启，直接打开仓库的 Pages 地址
2. **清空测试数据**：演示前在浏览器控制台执行 `localStorage.clear()`，保证收藏页初始为空、收藏按钮显示「✉️ 收藏这封回信」。
3. **备份**：提前录一段 2 分钟完整流程视频放在桌面，浏览器出问题时直接切视频。

## 开场（30 秒）

> （先展示首页屏幕，"解忧慢递邮局"标题）

**你**：
"评委好，我们的项目叫「解忧慢递邮局」，是一个面向大学生的轻量情绪陪伴**网页应用**。
当我们在校园里感到累了、烦躁了或者迷茫了，只要花一分钟选一下现在的心情，我们会给你一封校园回信，并推荐一个适合此刻的校园地点。

技术栈很轻：纯静态 HTML/CSS/JavaScript，原生 ES Modules，没有框架、没有构建步骤、没有后端、也没有调用任何大模型 API，推荐规则和文案全部在本地。两天内从零搭起来，现在可以跑通完整的情绪闭环。"

## 演示核心流程（2 分钟）

> （照下面顺序点，结果与当前数据一致）

**步骤 1：选心情**
- 点「疲惫 😴」
- 页面自动进入第 2 步

**步骤 2：选时间与偏好**
- 时长点「⏱️ 15 分钟」
- 偏好点「安静」
- 社交点「希望独处」
- 点「生成我的回信」

**步骤 3：看推荐结果**
- 当前数据下返回 3 张卡片：南湖综合楼水吧、文学院、梅园
- 每张卡片都带：类型、场景名、描述、「为什么推荐」、以及一条「👉 现在就能做的小事」
- 说明一句：推荐不是随机的，是按心情、可用时长、偏好、社交舒适度四个维度打分排序

**步骤 4：点开一张回信卡**
- 点「南湖综合楼水吧」
- 回信卡包含五部分：安慰文案、📍 推荐地点、📝 为什么是这里、👉 现在就能做的小事、结束语
- （念一句文案，温柔一点）

**步骤 5：收藏**
- 点「✉️ 收藏这封回信」
- 按钮变成「💌 已收藏（点击取消）」
- 说明：收藏只写进浏览器 localStorage，不上传服务器，换设备或清缓存就没了

**步骤 6：看收藏列表**
- 点右上角「📮 我的收藏」
- 看到刚才那封回信：📍 南湖综合楼水吧 + 收藏时间 + 回信正文 + 「取消收藏」

**步骤 7：反馈**
- 点「👍 适合我」
- 按钮变成「👍 已收到，谢谢你」，两个反馈按钮同时置灰（同一条回信只计一次反馈）

## 创新点说明（1 分钟）

**你**：
"创新点有三个：

第一，情绪 → **真实校园场景**的匹配，不是泛泛的鸡汤。15 个推荐地点都是华师桂子山和南湖校区真实存在的地方，每条都有具体描述和可执行的小行动。

第二，四个维度组合推荐：心情、可用时间、偏好、社交舒适度。同样是疲惫，只有 5 分钟和有 30 分钟，推荐的地点完全不同。

第三，载体是「校园回信卡」而不是弹一个建议框：有文案、有地点、有理由、有小行动，像真的收到一封信。

另外，整个项目零依赖、零安装、零后端，打开网页就能用，不收集任何用户数据。"

## 备用预案

| 万一… | 预案 |
|---|---|
| 浏览器卡住 / 页面白屏 | 一是确认是通过 HTTP 打开的（不是双击 `file://`）；二是切到提前录好的演示视频 |
| 本地服务器起不来 | 换端口重新起（如 `python -m http.server 8800`），或使用已部署的 Pages 地址 |
| 推荐结果和预期不同 | 不要硬解释，说明"推荐按四个维度打分，换一组选择结果会不同"，并现场换一个心情重来 |
| 评委要求看"没有匹配结果"的兜底 | 如实说明：兜底逻辑已写在代码里，但当前 15 条数据覆盖全部 6 种心情，正常选择下不会走到兜底分支，暂无法现场触发 |
| 评委问"为什么不做小程序" | "我们做的是纯静态网页应用，零依赖零安装，任何设备打开链接就能用，不需要经过小程序审核" |
| 评委问"图片为什么没有" | "场景图片字段已预留，当前版本优先保证功能闭环，图片是下一步的补充项" |
| 评委问"数据来源" | "15 条场景基于华师桂子山、南湖校区的真实地点，参考学校公开资料与地图信息核对后整理" |
| 评委问"有没有用 AI" | 如实回答 README 中的 AI 使用说明：AI 用于辅助开发与文档整理，产品本身不调用任何大模型 API |
